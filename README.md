# P2P Collaborative Editor with WebRTC

Проект для совместного редактирования файлов и чата через P2P соединение используя WebRTC.

## Технологии

- **Yjs** - CRDT библиотека для синхронизации данных
- **y-webrtc** - WebRTC провайдер для Yjs
- **CodeMirror 6** - редактор кода
- **Vite** - сборщик

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Откройте приложение в нескольких вкладках/браузерах с одинаковым именем комнаты для тестирования P2P соединения.

## Возможности

- ✅ Совместное редактирование текста в реальном времени
- ✅ P2P чат
- ✅ Отображение курсоров других пользователей
- ✅ Автоматическое переподключение
- ✅ Работает без собственного сервера (использует публичный signaling сервер)

## Как это работает

1. **Signaling** - используется публичный сервер `wss://signaling.yjs.dev` для установки соединения
2. **P2P соединение** - после установки соединения данные передаются напрямую между пользователями
3. **CRDT** - Yjs использует CRDT алгоритмы для разрешения конфликтов при одновременном редактировании
