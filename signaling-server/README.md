# WebSocket Signaling Server

Y-WebSocket сервер для синхронизации данных между клиентами.

## Запуск

```bash
docker-compose up -d
```

## Остановка

```bash
docker-compose down
```

## Логи

```bash
docker-compose logs -f
```

## Порты

- **1234** - WebSocket сервер

## Архитектура

Сервер использует **client-server** архитектуру, а не P2P:
- Все данные проходят через центральный сервер
- Сервер синхронизирует изменения между всеми подключенными клиентами
- Использует Yjs CRDT для разрешения конфликтов
