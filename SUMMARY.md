# Итоговая структура проекта

## ✅ Готово к использованию

### Файлы проекта:

```
webrtc/
├── signaling-server/           # WebSocket сервер
│   ├── server.js               # Yjs WebSocket сервер (без debug логов)
│   ├── Dockerfile              # Docker образ сервера
│   ├── docker-compose.yml      # Конфигурация Docker для сервера
│   ├── package.json            # Зависимости сервера
│   └── README.md               # Документация сервера
│
├── main.js                     # Клиентская логика (без debug логов)
├── index.html                  # Интерфейс приложения
├── package.json                # Зависимости клиента
├── vite.config.js              # Конфигурация Vite
├── Dockerfile                  # Docker образ клиента (Nginx)
├── nginx.conf                  # Конфигурация Nginx
├── docker-compose.yml          # Общая конфигурация Docker
└── README.md                   # Полная документация
```

## 🚀 Быстрый старт

### Запуск всего проекта:

```bash
docker-compose up -d --build
```

Откройте: http://localhost:3000

### Для локальной сети:

1. Запустите на сервере: `docker-compose up -d --build`
2. Узнайте IP: `ipconfig` (Windows) или `ip addr` (Linux)
3. Откройте на других устройствах: `http://<IP>:3000`

## ⚠️ Важно

**Это НЕ P2P соединение!**

Используется **Client-Server** архитектура:
- Все данные идут через центральный WebSocket сервер
- Сервер транслирует изменения между клиентами
- Для локальной сети это проще и надежнее чем WebRTC P2P
